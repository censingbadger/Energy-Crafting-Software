# Energy-Crafting-Software

A live classroom companion for **Energy Crafting for Resilient Leaders** (UNC Kenan-Flagler Executive Development).

- **[DESIGN.md](DESIGN.md)** — the full design proposal: one link, eight pills, live presenter dashboard, bio import, and after-class plans.
- **[prototype/index.html](prototype/index.html)** — clickable prototype with a simulated cohort. Open it in a browser and toggle between the Participant and Presenter views.

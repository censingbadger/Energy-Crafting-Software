# Energy-Crafting-Software

A live classroom companion for **Energy Crafting for Resilient Leaders** (UNC Kenan-Flagler Executive Development).

- **[DESIGN.md](DESIGN.md)** — the full design proposal: one link, eight pills, live presenter dashboard, bio import, and after-class plans.
- **[prototype/index.html](prototype/index.html)** — clickable prototype of the class companion with a simulated cohort. Toggle between the Participant and Presenter views.
- **[rater/index.html](rater/index.html)** — **Team Energy Rater**: a Nielsen-dial-style continuous rater. Observers watch a team work and tap (or press-and-hold) a 2×2 energy pad — high↔low energy by positive↔negative tone — while a moving time ribbon shows the activity elapsing. A facilitator dashboard overlays each rater's smoothed line with the team average, by team (1–10), with quadrant time-share stats and JSON export/import for merging ratings from multiple devices.
